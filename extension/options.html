Good Prompts

A clearer prompt in one click. You still press send.

1. Before you start

No account or API key is needed. Each installed copy gets a number of free rewrites a day.

2. Standing context (optional)

Sent with every rewrite so the engine guesses less. Leave any of it blank.

3. Try it

This sends the sample to Good Prompts with your saved settings. It counts as one of today's rewrites.


  


  

    
4. Use it

    
    
      
  1. Pin the extension: open the Extensions menu in Chrome's toolbar and click the pin beside Good Prompts.
    2. 
      
  2. Type a prompt in your AI chat (ChatGPT, Claude, Gemini and others) and leave the cursor in the box.
    3. 
      
  3. Click the icon, or press Alt+Shift+R (Option+Shift+R on a Mac).
    4. 
      
  4. Read the rewrite and press send yourself. Trigger again on an untouched rewrite to undo it.
    5. 
    

    
Change the shortcut at chrome://extensions/shortcuts.
